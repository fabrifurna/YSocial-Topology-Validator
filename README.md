# YSocial Topology Validator

**Addressing the Fluency Fallacy in LLM-Based Social Simulations**

This repository contains the code and analytical framework developed for my Master's Thesis in Data Science and Business Informatics at the University of Pisa. 

It introduces an independent, object-oriented Validation Framework to analyze the macroscopic network topology of LLM-driven Agent-Based Models (Social Digital Twins). The framework is applied to the trajectory databases generated by the Y-Social simulator (Tomašević et al., 2024).

## The Core Concept: The Fluency Fallacy

Current validations of LLM social simulations heavily rely on semantic metrics (e.g., text coherence, toxicity). However, because LLMs are highly articulate, researchers often fall into the **Fluency Fallacy**: assuming that linguistically coherent agents naturally aggregate into realistic social network structures. 

This framework shifts the validation paradigm from text to topology. By extracting Social Network Analysis (SNA) metrics (Scale-free distributions, Modularity, Clustering), this tool mathematically diagnoses intrinsic LLM biases, such as the **Average Persona Bias**, which actively destroys homophily and prevents the formation of realistic echo chambers.

## Repository Layout

The project is strictly decoupled. The core framework (`src/ysocial_validator/`) is agnostic and can process generic network data, while the execution scripts (`scripts/`) apply the framework to the Voat-simulation dataset.

    YSOCIAL-TOPOLOGY-VALIDATOR/
    ├── data/                      
    │   ├── 00_raw/                # Original SQLite trajectory databases
    │   └── 01_processed/          # Extracted metrics, statistical tests, and plots
    │
    ├── notebooks/                 # Exploratory data analysis
    │
    ├── scripts/                   # EXPERIMENT PIPELINES
    │   ├── 01_stage_a_validator.py       # Baseline topological stability extraction
    │   ├── 02_stage_a_visualization.py   # Baseline plotting
    │   ├── 03_stage_b_analyzer.py        # Sensitivity analysis extraction
    │   ├── 04_stage_b_visualization.py   # Condition comparison plotting
    │   └── 05_stage_b_hypothesis.py      # Mann-Whitney U tests for significance
    │
    ├── src/                       
    │   └── ysocial_validator/     # CORE FRAMEWORK
    │       ├── __init__.py
    │       ├── ingestion.py       # Data parsers and network builders
    │       ├── topometrics.py     # SNA metric extraction (Power-law, Modularity)
    │       └── stats.py           # Statistical testing utilities
    │
    ├── .gitignore
    ├── README.md
    └── requirements.txt

## Data Provenance

The raw SQLite databases required to run this pipeline are sourced from the public repository of the Y-Social Voat simulation study. 

* **Stage A (Baseline):** Requires the 30 benchmark runs.
* **Stage B (Sensitivity):** Requires the 110 runs across 11 OAT conditions (c0 to c10).

*Note: Raw databases are excluded from version control via `.gitignore` due to size constraints. They must be placed in `data/00_raw/` prior to execution.*

## Reproducibility and Usage

**1. Environment Setup**

    python -m venv venv
    source venv/bin/activate  # On Windows use: venv\Scripts\activate
    pip install -r requirements.txt

**2. Running Stage A: Baseline Stability**

Tests the default simulation engine for the emergence of scale-free properties and stable modularity over 30 independent runs.

    python scripts/01_stage_a_validator.py
    python scripts/02_stage_a_visualization.py

**3. Running Stage B: Sensitivity Analysis**

Evaluates the topological impact of LLM hyper-parameters (Temperature) and cognitive biases (Neutral Personas) across 110 runs, outputting Mann-Whitney U test significance.

    python scripts/03_stage_b_analyzer.py
    python scripts/04_stage_b_visualization.py
    python scripts/05_stage_b_hypothesis.py
