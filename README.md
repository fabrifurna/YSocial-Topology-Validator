# sdt-netval

## Addressing the Fluency Fallacy in LLM-Based Social Simulations

This repository contains the code and analytical framework developed for my Master's Thesis in Data Science and Business Informatics at the University of Pisa.

It introduces an independent, object-oriented validation framework for analysing the macroscopic network topology of LLM-driven Agent-Based Models (Social Digital Twins). The framework is applied to simulation databases generated by the Y-Social simulator (Tomašević et al., 2024) and the CNR/Rossetti platform, but is designed to be format-agnostic and reusable on any directed-graph simulation output.

## The Core Concept: The Fluency Fallacy

Current validations of LLM social simulations heavily rely on semantic metrics (e.g., text coherence, toxicity). Because LLMs are highly articulate, researchers often fall into the **Fluency Fallacy**: assuming that linguistically coherent agents naturally aggregate into realistic social network structures.

This framework shifts the validation paradigm from text to topology. By extracting Social Network Analysis (SNA) metrics — scale-free degree distributions, modularity, clustering — the tool mathematically diagnoses intrinsic LLM biases such as the **Average Persona Bias**, which suppresses homophily and prevents the formation of realistic echo chambers.

## Installation

    python -m venv venv
    source venv/bin/activate        # Windows: venv\Scripts\activate
    pip install -e .

After installation the `sdt-netval` command is available system-wide.

## Quick Start — Command Line

Analyse a single network file and print metrics to screen:

    sdt-netval analyze simulation.sqlite
    sdt-netval analyze edges.csv --output results/

Run the Stage A stability pipeline on a folder of simulation files:

    sdt-netval stage-a data/00_raw/02_cnr_baseline_stageA/ --output data/01_processed/02_cnr_baseline_stageA/

Run the Stage B sensitivity pipeline on a nested conditions folder:

    sdt-netval stage-b data/00_raw/03_cnr_recsys_stageB/ --output data/01_processed/03_cnr_recsys_stageB/

All commands accept `-v` for verbose logging and `--format json` to save JSON output alongside CSV.

## Quick Start — Python API

    from sdt_netval import load_network, GraphMetrics

    # Accepts .sqlite, .zip, or .csv — format auto-detected
    G = load_network("path/to/simulation.sqlite")
    report = GraphMetrics(G).generate_full_report()

For multi-run pipelines:

    from sdt_netval.pipeline import StageAValidator

    validator = StageAValidator("data/00_raw/02_cnr_baseline_stageA/")
    validator.process_runs()
    report = validator.full_stability_report()

## Data Provenance

Raw simulation files are excluded from version control (`.gitignore`). The folder structure is tracked via `.gitkeep` files.

**Legacy dataset (Tomašević et al., 2024)** — Y-Social Voat simulation:

- Stage A: 30 benchmark SQLite runs → `data/00_raw/01_legacy_tomasevic/benchmark_runs/`
- Stage B: 110 SQLite runs across 11 OAT conditions → `data/00_raw/01_legacy_tomasevic/sensitivity_runs/`

**CNR/Rossetti dataset** — new simulation platform:

- Stage A baseline: ZIP exports → `data/00_raw/02_cnr_baseline_stageA/`
- Stage B sensitivity: ZIP exports by condition → `data/00_raw/03_cnr_recsys_stageB/`
