# sdt-netval

**Addressing the Fluency Fallacy in LLM-Based Social Simulations**

This repository contains the code and analytical framework developed for my Master's Thesis in Data Science and Business Informatics at the University of Pisa.

It introduces an independent, object-oriented validation framework for analysing the macroscopic network topology of LLM-driven Agent-Based Models (Social Digital Twins). The framework is applied to the trajectory databases generated by the Y-Social simulator (Tomašević et al., 2024), but is designed to be format-agnostic and reusable on any directed-graph simulation output.

## The Core Concept: The Fluency Fallacy

Current validations of LLM social simulations heavily rely on semantic metrics (e.g., text coherence, toxicity). Because LLMs are highly articulate, researchers often fall into the **Fluency Fallacy**: assuming that linguistically coherent agents naturally aggregate into realistic social network structures.

This framework shifts the validation paradigm from text to topology. By extracting Social Network Analysis (SNA) metrics — scale-free degree distributions, modularity, clustering — the tool mathematically diagnoses intrinsic LLM biases such as the **Average Persona Bias**, which suppresses homophily and prevents the formation of realistic echo chambers.

## Quick Start

    from sdt_netval import load_network, GraphMetrics

    # Accepts .sqlite, .zip, or .csv — format auto-detected
    G = load_network("path/to/simulation.sqlite")
    report = GraphMetrics(G).generate_full_report()

`load_network` returns a standard `nx.DiGraph` regardless of the input format. `GraphMetrics` accepts any directed graph, not just Y-Social exports.

## Installation

**Development install** (recommended while the package is not yet on PyPI):

    python -m venv venv
    source venv/bin/activate        # Windows: venv\Scripts\activate
    pip install -e .

**Or install dependencies directly:**

    pip install -r requirements.txt

## Data Provenance

The raw simulation databases required to run the full pipeline are sourced from the Y-Social Voat simulation study (Tomašević et al., 2024) and must be placed in `data/00_raw/` before execution. Raw files are excluded from version control via `.gitignore`.

- **Stage A (Stability):** 30 benchmark runs with fixed parameters
- **Stage B (Sensitivity):** 110 runs across 11 OAT conditions (c0–c10)

## Running the Pipeline

### Stage A — Topological Stability

    python scripts/01_stage_a_validator.py
    python scripts/02_stage_a_visualization.py

### Stage B — Sensitivity Analysis

    python scripts/03_stage_b_analyzer.py
    python scripts/04_stage_b_visualization.py
    python scripts/05_stage_b_hypothesis.py

Alternatively, run the full pipeline interactively via `notebooks/01_data_exploration.ipynb`.
